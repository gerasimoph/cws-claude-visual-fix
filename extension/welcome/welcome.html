Browser Feedback for Coding Agents

Leave comments on your running app. Your coding agent fixes them — and the result is checked on the page.

  1. ✓

    Extension installed

    Comments and Copy as Markdown already work on any localhost page.

  2. 2

    Paste this into Claude Code

    Any folder works. It installs a small local helper and connects it to your agent. Nothing is added to your project.

    Waiting for the local helper…

  3. 3

    Review your app

    Restart Claude Code in your project folder and run /ui-review. Open your app on localhost — the review panel asks which project it is.

    Then hold Alt, click an element (↑ selects its parent), write what should change, press Enter. When you're done, press Fix all.

Browser context stays on your machine and goes directly to your own coding agent.
