Browser Feedback for Coding Agents

Point at what's wrong on your running app, say what should change, and hand it to Claude in one paste.

  1. ✓

    Extension installed

    Comments and Copy as Markdown already work on any localhost page.

  2. 2

    Review your page

    Open your app (localhost works out of the box). Hold Alt and click an element — ↑ or ↑ Parent selects a larger block. Write what should change, press Enter. Repeat for everything you want fixed.

    In DevTools device mode press Alt⇧C, then tap.

  3. 3

    Copy for Claude, paste, done

    Press Copy for Claude in the review panel and paste into Claude (Claude Code, the Claude app, or any other agent). It gets your comments with instructions and hints to find the code: component, file, heading, text.

    When the page updates, pins turn to Changed — check. Look, then Accept or Reopen.

  4. +

    Optional: let Claude Code fix comments by itself

    Paste this into Claude Code once. It installs a small local helper; then a Fix all button sends comments straight to your Claude Code session — no copy-paste. Nothing is added to your project.

    Not installed — copy mode works without it.

Browser context stays on your machine and goes directly to your own coding agent.
